# MedCL

本地医学影像持续学习**评测**工作台。顶部导航和纵向任务层级、中文 Streamlit 界面、SQLite 队列、一个独立评分 worker；不训练、不调参、不聚合权重、不要求训练日志。

## 启动与使用

本次交付的电脑已使用现有 Python 环境安装依赖。双击 `启动MedCL.command`，浏览器访问 **http://127.0.0.1:8501**。保持启动窗口打开；关闭窗口停止服务。数据盘需挂载。

另一台电脑首次部署由管理员执行：

```sh
python3 -m pip install -r requirements.txt
python3 run.py
```

使用 Python 3.12；已存在的环境即可，不需要 Torch 或 GPU。macOS 启动器优先复用 `/opt/miniconda3/bin/python`，也可用 `MEDCL_PYTHON` 指定现有解释器。不要向公网绑定端口。

网页操作：顶部任务中心 → 分割 / 分类 / 配准 → 域 / 类 / 任务增量 → 具体协议 → 上传模型或预测 → 查看矩阵、病例可视化与报告。分割在选协议前记录“全监督 / 弱监督”的提交者声明；两者都用冻结完整测试标注评分。更改顺序或监督条件需新建评测。

新克隆默认提供三种**合成验收协议**，真实基准显示“待接入”。管理员按 `settings.example.json` 建立不入库的 `settings.local.json`；不得将真实路径、数据、标签、模型或原论文私有材料提交到仓库。

## 支持与边界

| 范围 | 已实现 | 边界 |
|---|---|---|
| 分类 | 图像准确率、类别增量、类别语义名称、全局编码、逻辑客户端联邦评分模拟 | 无患者 ID 时不声称患者级评测；没有联邦训练或通信 |
| 分割 | HDF5 固定测试集、全/弱监督声明、病例体积前景 Dice、原图/预测叠加图 | 可视化不带隐藏真值；不根据二维切片臆造 HD95 毫米值 |
| 配准 | 对应标志点 TRE、移动点/预测点可视化、坐标/单位检查、任务增量 | 当前只有合成可视化；真实点对尚未接入，不支持任意位移场或 SAMCL 模型 |
| 阶段 | 单个最终输入、多个或缺失阶段、自定义顺序 | 不推断缺失阶段，不把最后可见阶段当作最终阶段 |
| 客户端 | 固定病例轮转划分，分类按图像；全局/各客户端矩阵、宏平均、加权分类准确率、最差与差异 | 仅逻辑客户端评分模拟，不代表真实跨医院联邦部署 |
| 模型 | 三种已审核纯数值结构，float32 safetensors | 未接入 UNet / EfficientNet / SAMCL 或任意上传代码；这些方法可提交预测 |
| 输出 | 任务主指标、Final average / BWT / Forgetting / FWT / BWTR、病例可视化、三类报告 | 条件不足显示不可计算；不把不同任务指标混为总分 |

客户端版本为 `case-round-robin-v1-cN`：每个任务的匿名病例序号 `mod N`，不会拆分同一病例。分类没有患者标识时按该任务图像列表轮转。它是平台新定义的测试划分，不是原论文的客户端划分。

`Final average` 是最终各任务等权宏平均；分类的客户端样本加权准确率按各客户端实际样本数计算，不与任务宏平均混淆。缺少阶段、参照或客户端样本时显示 `—`，JSON 为 `null`，CSV 留空并附原因。BWT / 遗忘要求对应历史观测完整；无随机初始化或独立训练参照时 FWT / RMA 不可计算。TRE 越低越好，其“最差客户端”取最大值。完整定义见 [协议说明](docs/PROTOCOLS.md)。

## 提交格式与示例

阶段位置和输出头在网页选择，不需要用户另写配置清单。每阶段一个文件。支持 JSON 或平铺 NPZ/ZIP 预测；匿名样本索引由页面生成下载，不包含标签。

```json
{"schema":"medcl.predictions.v1","tasks":{"T1":{"sample_ids":["T1-s000000"],"predictions":[0]}}}
```

上例只说明结构，不是完整测试提交。NPZ/ZIP 内每个任务必须成对包含 `T1__ids.npy`、`T1__pred.npy`；禁止目录、符号链接、Pickle 和对象数组。不在磁盘解压 ZIP。样本 ID 必须完整且唯一，平台按 ID 对齐；分类/分割预测必须是合法整数标签。默认每阶段覆盖已见任务，只有协议和输出头允许时才可选择未见任务。

页面提供无需终端的完整合成预测与未训练权重下载。开发者也可生成多阶段示例（输出在私有状态目录，默认不覆盖已有文件）：

```sh
python3 -m medcl.examples --benchmark demo-classification --all-stages
python3 -m medcl.examples --benchmark demo-segmentation
python3 -m medcl.examples --benchmark demo-registration
```

所有例子均为未训练工程基线，不能引用为医学或论文性能结果。结构的权重尺寸、预处理和配准约定见 [协议说明](docs/PROTOCOLS.md)。

## 存储与安全

- 默认私有状态目录：`~/.local/state/medcl`；可用 `MEDCL_STATE_DIR` 改为独立目录。内含 SQLite、上传、冻结配置、结果、最多 6 个/任务的私有预览和错误日志；隐藏真值不进入预览。
- `MEDCL_CONFIG` 可指定管理员配置文件；网页不接受任意本地路径。测试资产只读、不复制入源码；提交时保存大小/修改时间，执行前检查资产是否改变，不额外做全量哈希。
- 每文件 128 MiB、每次合计 256 MiB；NPZ 展开后最多 512 MiB、最多 12 个任务。严格校验 JSON、数组和 safetensors 的内容、大小、映射。
- 模型在原生 macOS 沙箱中运行：不提供标签，清空继承环境，禁止网络、其他用户文件和子进程；推理 120 秒墙钟/90 秒 CPU、2 GiB RSS 轮询限制。评分任务另有 10 分钟墙钟/4 GiB RSS 轮询上限。内存轮询不是瞬时硬配额。
- 必须先通过实际隔离探针；不支持该沙箱的环境只开放预测评分，不降级执行模型。只测试了 macOS/Python 3.12；Linux 模型隔离未实现，Windows worker 不支持。
- 这是本机单用户工具，不是公网多租户服务或临床系统。没有身份认证、配额管理或公开托管；本地报告仍由操作者决定是否适合分享。请勿上传个人信息或敏感元数据。

实现路径：`app.py` 界面；`medcl/benchmarks.py` 只读资产适配；`submissions.py` / `storage.py` 提交与冻结；`worker.py` / `runner.py` 独立评分；`sandbox.py` / `infer.py` 受限推理；`metrics.py` 指标；`reports.py` 导出。未引入额外数据库、Web 后端或训练服务。

## 验收与资产状态

```sh
python3 -m unittest discover -s tests -v
```

检查包括可手算指标、无日志最终输入、自定义顺序、缺失阶段、空客户端、监督条件比较门、不带真值的分割/配准预览、非法输入、真实沙箱与页面提交。真实数据工程验收及浏览器记录见 [测试报告](docs/TEST_REPORT.md)，本轮全局聚合证据见 [acceptance_summary_v2.json](docs/acceptance_summary_v2.json)。

需要公开聚合报告时，管理员可明确选取已完成的评测：`python3 -m medcl.reports JOB_ID --output aggregate.json`。此导出不包含病例或客户端明细，但发布前仍需检查方法名称和协议文字；不会自动发布本地数据库或网页下载的完整病例报告。

故障处理：页面显示 worker 离线时重启启动器；任务失败时查看记录里的原因和私有任务目录日志。原配置/上传保留，不自动修改或重跑失败任务。旧 worker 意外中断的运行任务会在下次启动时标记失败。
