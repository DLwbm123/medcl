## 三维预览资产契约

- 分割 HDF5 仍以 HWN 切片和病例结束索引为评分输入；评分器按病例堆成 ZYX，仅把原图与**预测** labelmap 写入私有预览。隐藏测试标签不进入浏览器。
- 体数据配准管理员资产为同形 `[N,Z,Y,X]` fixed/moving volumes 和 `[N,K,3]` moving/fixed points。提交者可额外给出已在外部对齐 fixed grid 的 registered volume 与 warped prediction；平台只展示，不执行配准或重采样，主指标仍为 TRE。
- 每个阶段任务确定性选择至多 3 个病例，并把每轴限制到 128、总体限制到 1,000,000 voxel。预览是有损显示资产，不是原始医学数据副本或科研归档。
- 未登记 spacing 时使用 `[1,1,1]` 索引空间；未登记完整 origin/direction 时不声称病人方向。查看器用于论文范围内只读质控，不替代 ITK-SNAP。
- 体数据只留在 0600 私有预览文件和短生命周期浏览器信封中；JSON/CSV/HTML 与公开 aggregate 不包含这些数组，也不发布服务器路径、病例 ID 或截图。

## 本轮私有真实数据冒烟

在用户指定的 GPU 服务器上，以一个真实前列腺分割测试 HDF5 做了只读链路检查：72 张切片、3 个病例，图像/标签均为 `256×256×72`，病例边界完整覆盖测试集。测试把该数据的分割标签原样作为“假定模型输出”提交，因此前景 Dice 和最终任务宏平均按定义均为 **1.0**。评分生成 3 个 `segmentation-volume` 私有预览；检查到的浏览器信封只包含 `image` 与 `prediction`，不含隐藏 target。

这是一项恒等回放测试，只验证真实 HDF5 读取、匿名 ID 对齐、病例聚合 Dice、私有三维预览和 envelope 编解码；**不是模型推理、泛化效果、论文实验结果或临床结论**。服务器原始资产未修改；测试结束后删除了本轮临时源码、上传、结果和预览。服务器地址、账号、实际路径、病例标识和医学影像截图未进入仓库。

## 模型缺口

已检查的候选位置主要是 PT/PTH 格式，没有找到可直接用于当前审核结构的已训练 safetensors 或合规预测包。没有为“看起来完成”而不安全加载/转换历史 checkpoint，也没有重新训练。

本轮使用的三类示例结构是未训练线性分类器、逐像素阈值器和标志点零位移；真实数据上产生的分数只证明评测链路工作，不证明方法有效。接入既有研究模型有两条明确路径：

1. 用户在原可信模型环境中导出符合样本 ID / 全局类别 / 坐标契约的预测，直接在网页提交；无需改动原训练工程。
2. 明确结构、纯权重键、预处理、输出语义和测试条件后，另行审核适配器及隔离测试；不运行任意上传依赖。

合成分类、分割、配准协议必须全部任务均为 `format=synthetic` 且顶层严格为 `synthetic=true`，否则配置加载立即失败；界面和报告均作警示，不会用合成结果补齐真实数据缺口。

## 资产版本边界

当前平台按已明确的轻量运维策略，在提交时记录每个资产的大小与 `mtime_ns`，并在实际读取每个任务前复查；未观察到异常时不主动计算全量 SHA-256。它可以发现离线、大小或修改时间变化，但不能证明内容身份，也无法检测“同大小替换后恢复原 mtime”的改动。若工具报错、数量/大小异常、读取失败或出现损坏迹象，应先局部定位疑点资产，再决定是否对受影响文件追加内容摘要；因此当前报告不得称测试资产已按内容摘要冻结。
