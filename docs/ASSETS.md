## 模型缺口

已检查的候选位置主要是 PT/PTH 格式，没有找到可直接用于当前审核结构的已训练 safetensors 或合规预测包。没有为“看起来完成”而不安全加载/转换历史 checkpoint，也没有重新训练。

本轮使用的三类示例结构是未训练线性分类器、逐像素阈值器和标志点零位移；真实数据上产生的分数只证明评测链路工作，不证明方法有效。接入既有研究模型有两条明确路径：

1. 用户在原可信模型环境中导出符合样本 ID / 全局类别 / 坐标契约的预测，直接在网页提交；无需改动原训练工程。
2. 明确结构、纯权重键、预处理、输出语义和测试条件后，另行审核适配器及隔离测试；不运行任意上传依赖。

合成分类、分割、配准协议始终带 `synthetic=true`，界面和报告均作警示；不会用合成结果补齐真实数据缺口。
