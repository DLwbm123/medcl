# 首页插画与图标来源

这些文件只属于展示层，不属于医学测试资产、模型输出或评分结果。

`medical-background.webp` 和四个 `illustration-*.webp` 来自项目所有者在本次设计对话中认可的 AI 生成首页效果图：只截取医学风格装饰区域和图像缩略区域，移除装饰文字、淡化裁切边缘，再保存为本地 WebP。没有读取真实患者、测试影像、隐藏真值或外部图库。它们不是可用于研究或诊断的医学图像。

原始参考图（只留在交付包 reference/，不会由更新器复制到代码仓库）：
- 文件：`approved-homepage-reference.png`
- 原尺寸：1672 × 941
- 图像区域裁切以 1648 × 928 的归一化坐标为基准。
- 实际界面中的所有标题、按钮、矩阵、列表、计数都仍然是代码生成的元素，而不是整张效果图覆盖或透明点击热区。

图标由 `medcl/homepage_ui.py` 内的原创 SVG 路径生成，并通过 `<img src="data:image/svg+xml;base64,...">` 与 CSS 背景使用，不依赖图标字体、CDN 或外链。SVG 自身不执行脚本。

首页展示固定标注“功能示意 · 非实验结果 · 非真实病例”。真实记录与真实协议数量仍从现有数据读取；图像和示意矩阵不进入数据库、正式报告或评测 API。

本目录不需要 Node、Pillow 或 OpenCV 才能运行。Python 标准库负责读取并编码本地素材。未更改静态服务开关，也未将私有路径映射到 HTTP。
